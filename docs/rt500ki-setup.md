# RT-500KI 設定

対象ファームウェアは 08.01.0000、使用する IP 端末番号は 3 です。

1. RT-500KI の Web 設定画面を開く。
2. 電話設定の内線設定で、IP 端末 3 を音声専用として有効にする。
3. IP 端末 3 のユーザー名／内線番号を `3` とし、推測されにくい 32 文字の
   ランダムなパスワードを設定する。
4. PC の LAN アドレスを固定 DHCP リース等で安定させる。
5. Hikari Phone の設定に RT-500KI の LAN アドレス、PC の LAN アドレス、
   IP 端末 3 のパスワードを入力する。

パスワードはこの文書、ログ、Issue、チャットへ貼り付けないでください。
SIP は同一 LAN 内だけで利用し、ルーターで 5060/UDP や RTP ポートを転送しません。

既存電話機は撤去せず、110、118、119 および停電時を含む緊急時の通話手段として
維持します。
