# 手動受入試験

- Tailscale 上の Asterisk に、ユーザ ID を SIP 識別子（AoR）と
  ダイジェスト認証名の両方に使って登録・登録解除
- Asterisk 再起動、Tailscale 再接続、アプリ再起動後の再登録
- ユーザ ID 1～32 文字とパスワード 1～128 文字について、許可する記号、
  最小値、最大値、範囲外の境界値を検証
- 先頭の 0 を含む内線番号へ発信できることを検証
- 内線と外線について発信／着信を各 20 回反復
- 30 分間の連続通話で音声、RTP、メモリ利用が安定
- 発信取消、着信拒否が正しく終了し、拒否は 486 になる
- 110、118、119 が SIP INVITE の送信前に拒否される
- DTMF が RTP telephone-event とインバンドの両方で動作
- ミュート中も呼が維持され、解除後に送話が復帰
- ウィンドウを閉じても待受し、トレイから復帰／終了できる
- マイク、通話出力、着信音出力を別々に選択できる
- ネットワーク切断、スリープ復帰、Tailscale 再接続、Asterisk 再起動後に回復
- 保存済み資格情報や完全な電話番号がログへ出ない

実機試験中も既存電話機を利用可能な状態に保ちます。
