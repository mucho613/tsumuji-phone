# 初期リリース要件

## 対象

- NTT 西日本のひかり電話、RT-500KI（ファームウェア 08.01.0000）
- 同一 LAN 内のみ。SIP を外部ネットワークや VPN へ公開しない
- 最初の端末は Ubuntu 24.04。次に Windows 11 x64、Android 12/API 31+
- RT-500KI の IP 端末 3 を一つだけ使用

## 通話

- 外線／内線の発信と着信、番号表示、応答、拒否、取消、切断
- 単一アカウント、単一通話。二つ目の着信には `486 Busy Here`
- SIP UDP/IPv4、サーバー／ローカル SIP ポート 5060
- RTP/RTCP は 40000-40009。LAN 経路のローカルアドレスへ明示的に bind
- PCMU（G.711 μ-law、8 kHz、20 ms）のみ
- DTMF は RTP telephone-event を優先。未交渉時はインバンドへフォールバック
- ミュート中も無音 RTP を維持
- 110、118、119 は発信禁止

## デスクトップ

- 400x680、最小 360x600 の小型ウィンドウ
- 閉じる操作ではトレイへ格納。明示的な終了メニューを提供
- マイク、通話出力、着信音出力を独立選択。初期値は全て OS 既定
- 通話中のデバイス消失時は通話を終了し、途中切替は行わない
- OS キーチェーンへ SIP パスワードを保存。フロントエンドへ保存値を返さない
- テレメトリー、録音、通話履歴、連絡先は持たない

## 初期対象外

保留、転送、通話待ち、複数通話、複数 HGW、映像、FAX、高音質コーデック、
LAN 外接続、自動更新、OS 起動時の自動待受、録音。
